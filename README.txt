MAC@SHEFF DECOR — WEBSITE

Pages
- index.html: homepage with the brand introduction, How We Work, selected visuals, service overview and enquiry CTA.
- portfolio.html: filterable gallery of owner-supplied design visuals with an image viewer.
- services.html: detailed descriptions of the services offered.
- about.html: studio introduction and working values.
- contact.html: enquiry form that opens a prefilled WhatsApp message.

Assets
- assets/portfolio/: owner-supplied portfolio and interior design visuals.
- asset/images/: additional owner-supplied images and illustrations, including exterior visuals.
- assets/logo.png: supplied logo file; the site uses a text wordmark for the Mac@Sheff Decor name.

Run locally
Open index.html in a browser or serve this folder with a static web server.
